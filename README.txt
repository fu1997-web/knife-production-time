生産時間管理アプリ

GitHub Pagesへのアップロード：このZIPを解凍し、中の index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png をリポジトリの一番上にアップロードしてください。

番号のルール：
・包丁番号 KN003〜KN027：包丁の種類ごとの固定番号
・ロットID LOT-261012-01 など：製造するまとまりごとの番号
・バーコード読み取りはロットIDを読み取ります。包丁番号は画面の包丁種類選択で指定します。

作業開始時に包丁種類、ロットID、数量、工程を指定し「開始」。終了時は同じロットIDと工程を選択して「終了・保存」またはロットバーコードを再読取します。

注意：記録は利用中のブラウザ内に保存されます。定期的に「データをバックアップ」してください。カメラ読取はHTTPSとカメラ許可が必要です。
