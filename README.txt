生産時間管理｜アニメーション版

追加した動き：
- ページ表示時の控えめなフェードイン
- ボタンを押したときのタップ反応
- 入力欄フォーカス時のハイライト
- 作業開始時のアクティブ表示アニメーション
- ロット終了・保存時の成功アニメーション
- カードやステータスの滑らかな切り替え
- OSで「視差効果を減らす」設定をしている場合はアニメーションを抑制

運用：
- 包丁名は漢字で選択
- ロット番号と工程番号はバーコード読み取り
- 工程バーコードで作業開始
- 終了時はロット番号を読み取ると、そのロットの計測中工程をすべて終了・保存

GitHub Pagesに反映するには、ZIPを解凍して中身をリポジトリ直下にアップロードし、既存ファイルを置き換えてください。
