# 10丁単位 製造時間管理（実用版パッケージ）

## できること
- ロットIDと数量（初期値10丁）を管理
- 工程別タイマー（鍛造、下処理、研削、焼入れ、歪取り、研磨、柄付け、仕上げ・検品）
- 一時停止・再開、終了保存
- 作業履歴、工程別集計、CSV出力、JSONバックアップ/復元
- PWA用マニフェストとサービスワーカーを同梱

## iPhoneで使うために
1. このZIPをHTTPS対応の静的ホスティング（例：GitHub Pages等）へアップロードします。
2. 公開されたHTTPS URLをiPhoneのSafariで開きます。
3. 共有ボタン →「ホーム画面に追加」でアプリのように起動できます。
4. QR読み取りは端末・ブラウザのBarcodeDetector対応状況に依存します。読取できない場合は「コード入力」を使ってください。

## 大事な制約
- 現状、データはその端末・ブラウザ内に保存されます。複数端末間の自動同期はありません。
- ブラウザのデータ消去や端末故障に備え、定期的に「データをバックアップ」でJSONを保存してください。
- 複数人で同じ記録を共有する本格運用には、Google Sheets/AppSheetやデータベース連携の追加が必要です。
- 作業時間はタイマーの開始・一時停止・終了で記録します。開始時刻と終了時刻の差ではなく、一時停止を除いた経過時間です。
