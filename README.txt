生産時間管理アプリ（バーコード中心操作版）

【バーコードの種類】
・包丁番号：KN003 など（包丁の種類ごとに固定）
・ロット番号：LOT-261012-01 など（製造のまとまりごとに設定）
・工程番号：PR-02 ～ PR-16（工程ごとに固定）

【使い方】
1. GitHub Pagesでindex.htmlを開き、「スキャン開始」を押してカメラを許可します。
2. 新しい製造ロットでは、包丁番号（例 KN003）を読み取ります。
3. ロット番号（例 LOT-261012-01）を読み取ります。包丁番号とロット番号の対応はこのブラウザに保存されます。
4. 工程番号（例 PR-03）を読み取ると計測開始します。
5. 同じロットで同じ工程のバーコードをもう一度読むと、計測終了・自動保存します。
6. 次の工程やロットは、それぞれのバーコードを読み取ります。スキャナーは「スキャン停止」を押すまで開いたままです。

【ラベル印刷】
「バーコードラベル作成.html」を開き、必要なロット番号を1行ずつ入力して「ラベルを作成」→「印刷する」を押してください。ラベル作成にはインターネット接続が必要です。包丁番号・工程番号はあらかじめ一覧を作成します。

【注意】
・カメラ利用にはHTTPS（GitHub Pagesなど）とカメラ許可が必要です。
・記録は利用中のブラウザ内に保存されます。別端末との共有はしません。定期的にバックアップを保存してください。
・同じロット内で包丁種類を変更しないでください。違う種類は別ロットにしてください。
・工程バーコードの2回目の読み取りで終了します。読み間違いを避けるため、画面の対象ロットと工程を確認してください。
